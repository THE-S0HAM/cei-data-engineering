# Celebal Excellence Internship - Data Engineering

## 🎯 Internship Overview

This repository contains the complete portfolio of assignments, projects, and learning materials from the **CEI (Celebal Excellence Intern) Program** at **Celebal Technologies** (15 June 2026 - 15 August 2026).

The program provides a structured, industry-oriented learning experience focused on building strong Data Engineering fundamentals through guided learning, mentorship, and hands-on project development.

## 🚀 Learning Objectives

- Master data processing with **Python** and **Pandas**
- Develop expertise in **SQL** for data manipulation and analysis
- Implement scalable data pipelines with **Apache Spark**
- Build cloud-based solutions using **Microsoft Azure**
- Design and optimize **ETL/ELT** processes
- Implement **Delta Lake** for data lakehouse architecture
- Develop professional **Git** workflows and documentation practices
